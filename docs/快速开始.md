# 快速开始

本文档描述如何从 0 到 1 完成 Higo、Higo2OV（本代码仓）、OpenViking 三方的部署与对接。

---

## 1. 部署 OpenViking

### 环境要求

- Python 3.10+
- OpenViking 服务端已安装并运行

### 启动 OpenViking 服务

```bash
# 示例：OpenViking 默认监听端口 1933
python -m openviking.server.bootstrap --host 127.0.0.1 --port 1933
```

验证服务是否启动：

```bash
curl http://127.0.0.1:1933/health
# 期望返回: {"status": "ok"}
```

---

## 2. 部署 higo2ov

### 环境要求

- Python 3.10+
- pip

### 安装依赖

```bash
cd /path/to/higo2ov
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
```

### 配置环境变量

在项目根目录创建 `.env` 文件：

```bash
# OpenViking 连接配置
OPENVIKING_BASE_URL=http://127.0.0.1:1933
OPENVIKING_ROOT_API_KEY=your-root-api-key
OPENVIKING_AGENT_ID=default
OPENVIKING_USER_ID=default

# HTTP 超时
OPENVIKING_TIMEOUT_MS=30000

# 自动归档阈值
OPENVIKING_COMMIT_TOKEN_THRESHOLD=8000

# 记忆召回配置
OPENVIKING_RECALL_LIMIT=10
OPENVIKING_RECALL_SCORE_THRESHOLD=0.1
OPENVIKING_RECALL_TOKEN_BUDGET=2000
OPENVIKING_RECALL_RESOURCES=false

# 捕获与召回开关
OPENVIKING_AUTO_CAPTURE=true
OPENVIKING_AUTO_RECALL=true

# Session 隔离配置
OPENVIKING_ISOLATE_USER_SCOPE_BY_AGENT=false
OPENVIKING_ISOLATE_AGENT_SCOPE_BY_USER=true

# Bypass 配置
OPENVIKING_BYPASS_SESSION_PATTERNS=""

# 诊断日志
OPENVIKING_EMIT_DIAGNOSTICS=true
```

详细配置说明见 `docs/engine/配置说明.md`。

### 启动 higo2ov

```bash
# 开发模式（带热重载）
python main.py
# 或
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 生产模式
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

验证启动：

```bash
curl -X POST http://127.0.0.1:8000/ \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "probe",
    "protocolVersion": "2026-05-25",
    "source": "higo",
    "session": {"sessionId": "test-session"},
    "timestamp": "2026-05-26T10:00:00Z"
  }'
```

## 3. 在 Higo 中配置接入

### 开启配置面板

Higo 前端：
```bash
VITE_SESSION_MEMORY_ENGINE_SETTINGS_ENABLED=true
```

Higo 后端：
```bash
SESSION_MEMORY_ENGINE_SETTINGS_ENABLED=true
```

### 配置流程

1. 打开 Higo 前端，进入任意 Session
2. 点击右侧边栏「会话配置」Tab
3. 填写 Endpoint：`http://<higo2ov-host>:8000`
4. 点击「测试 endpoint」验证连通性
5. 开启「启用自定义记忆引擎」，保存配置

### 全局配置（可选）

```bash
GLOBAL_MEMORY_ENGINE_ENDPOINT=http://<higo2ov-host>:8000
```

## 5. 常见问题排查

### Higo 前端没有「会话配置」Tab

**原因**: `VITE_SESSION_MEMORY_ENGINE_SETTINGS_ENABLED` 未设置

**解决**: 在 Higo 前端 `.env` 中添加并重新构建。

### Higo 测试 endpoint 失败

1. 确认 higo2ov 已启动
2. 确认 Higo 前端填写的 endpoint 正确
3. 从 Higo 后端服务器直接测试
4. 检查 higo2ov 日志是否有 `[handle] mode=probe`
5. 检查防火墙

### higo2ov 无法连接到 OpenViking

1. 确认 OpenViking 已启动：`curl http://<host>:1933/health`
2. 检查 `.env` 中的 `OPENVIKING_BASE_URL`
3. 确认 `OPENVIKING_ROOT_API_KEY` 已配置
4. 检查网络连通性

### Higo 报 `SESSION_MEMORY_ENGINE_INVALID_RESPONSE`

1. 检查 `result.request` 是否只包含 `messages` 一个字段
2. 检查是否完整保留了 system、context_env、current_user
3. 检查最后一条 `role="user"` 是否是 current_user

### 记忆没有被注入

1. 检查 `OPENVIKING_AUTO_RECALL=true`
2. 检查用户输入是否被过滤为空
3. 查看 `[recall] after rerank=0`
4. 检查是否被 bypass

### 记忆没有被捕获

1. 检查 `OPENVIKING_AUTO_CAPTURE=true`
2. 检查文本是否被清理为空
3. 查看 `[capture]` 日志
4. 检查 `pending_tokens` 是否未达阈值
