# 配置说明

## 概述

配置通过 `.env` 文件加载，由 `engine/config.py` 中的 `OpenVikingConfig` Pydantic 模型统一管理。

---

## 环境变量全表

### 连接配置

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_BASE_URL` | 是 | `http://127.0.0.1:1933` | OpenViking 服务地址 |
| `OPENVIKING_ROOT_API_KEY` | 否 | `""` | ROOT API Key，仅用于 admin 操作 |
| `OPENVIKING_AGENT_ID` | 否 | `default` | 默认 Agent ID |
| `OPENVIKING_USER_ID` | 否 | `default` | account 下默认用户的 user_id |
| `OPENVIKING_ACCOUNT_REGISTRY_PATH` | 否 | `.account_registry.json` | 账户注册表本地持久化路径 |
| `OPENVIKING_TIMEOUT_MS` | 否 | `30000` | HTTP 超时（毫秒） |

### 归档配置

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_COMMIT_TOKEN_THRESHOLD` | 否 | `8000` | 自动归档触发阈值 |

### 召回配置

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_RECALL_LIMIT` | 否 | `10` | 搜索返回上限 |
| `OPENVIKING_RECALL_SCORE_THRESHOLD` | 否 | `0.1` | 召回最低相似度阈值 |
| `OPENVIKING_RECALL_INJECT_LIMIT` | 否 | `6` | 注入记忆条数上限 |
| `OPENVIKING_RECALL_TOKEN_BUDGET` | 否 | `2000` | 记忆注入 token 预算 |
| `OPENVIKING_RECALL_RESOURCES` | 否 | `false` | 是否搜索 resources |

### 捕获配置

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_AUTO_CAPTURE` | 否 | `true` | 是否自动捕获对话消息 |
| `OPENVIKING_AUTO_RECALL` | 否 | `true` | 是否自动召回记忆 |
| `OPENVIKING_CAPTURE_MODE` | 否 | `semantic` | 捕获模式：`semantic` 或 `keyword` |
| `OPENVIKING_CAPTURE_MAX_LENGTH` | 否 | `8192` | 单条消息最大捕获长度 |

### 作用域隔离

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_ISOLATE_USER_SCOPE_BY_AGENT` | 否 | `false` | 用户是否按 Agent 隔离 |
| `OPENVIKING_ISOLATE_AGENT_SCOPE_BY_USER` | 否 | `true` | Agent 是否按用户隔离 |

### Bypass

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_BYPASS_SESSION_PATTERNS` | 否 | `""` | 跳过处理的 session 模式，逗号分隔的 glob 表达式 |

### 诊断

| 环境变量 | 必填 | 默认值 | 说明 |
|----------|------|--------|------|
| `OPENVIKING_EMIT_DIAGNOSTICS` | 否 | `true` | 是否输出结构化诊断日志 |

---

## 配置模型

```python
class OpenVikingConfig(BaseModel):
    base_url: str = "http://127.0.0.1:1933"
    api_key: str = ""
    agent_id: str = "default"
    account_registry_path: str = ".account_registry.json"
    user_id: str = "default"
    timeout_ms: int = 30000
    commit_token_threshold: int = 8000
    recall_limit: int = 10
    recall_score_threshold: float = 0.1
    recall_inject_limit: int = 6
    isolate_user_scope_by_agent: bool = False
    isolate_agent_scope_by_user: bool = True
    auto_capture: bool = True
    auto_recall: bool = True
    capture_mode: str = "semantic"
    capture_max_length: int = 8192
    bypass_session_patterns: str = ""
    recall_token_budget: int = 2000
    recall_resources: bool = False
    emit_diagnostics: bool = True
```
