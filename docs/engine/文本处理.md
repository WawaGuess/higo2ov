# 文本处理

## 概述

`engine/text_utils.py` 提供文本清洗、捕获决策、消息格式转换等工具函数。
`utils/token_utils.py` 提供统一 token 计数（优先 tiktoken，fallback 字符估算）。

---

## 文本清洗

### sanitize_user_text_for_capture(text)

用于捕获前的文本清洗，按顺序执行：

| 步骤 | 过滤内容 | 正则/逻辑 |
|------|---------|----------|
| 1 | HEARTBEAT 消息 | `\bHEARTBEAT(?:\.md\|_OK)\b` |
| 2 | Compacted system messages | 提取 `System: [...] Compacted (...)` 中的实际内容 |
| 3 | relevant-memories 块 | `<relevant-memories>[\s\S]*?</relevant-memories>` |
| 4 | Conversation metadata | `Conversation info/metadata...` |
| 5 | Sender metadata | `Sender (...)...` |
| 6 | think 块 | `<think>[\s\S]*?</think>` |
| 7 | Fenced JSON metadata | ````json...````，若含 ≥3 个 metadata key |
| 8 | 前导时间戳 | `[2026-06-04 10:00:00]` 等格式 |
| 9 | Null bytes | `\u0000` |
| 10 | 空白折叠 | 多个空白字符折叠为单个空格 |

## 捕获决策

### get_capture_decision(text, mode, capture_max_length)

返回 `{"should_capture": bool, "reason": str, "normalized_text": str}`

过滤链：
1. 空文本检查
2. 长度检查（CJK min=0，EN min=10）
3. 命令文本过滤
4. 纯标点过滤
5. Subagent context 过滤
6. 纯问句过滤（带 memory intent 除外）
7. Mode 分支：
   - `semantic`：通过过滤即捕获
   - `keyword`：匹配 7 组 trigger regex 才捕获

### 7 组 Memory Trigger

1. `remember|preference|prefer|important|decision|decided|always|never`
2. 中文：记住、偏好、喜欢、重要、决定、总是、爱好、擅长 等
3. 邮箱格式
4. 电话号码格式
5. 自我介绍：`我是/叫/名字/name/住在`
6. 情感表达：`喜欢/崇拜/讨厌/害怕/擅长`
7. 英文情感：`favorite|love|hate|enjoy|dislike`

## 消息转换

### message_to_ov_parts(message)

将 Higo 消息转换为 OpenViking parts 格式：

| Higo role | OV part type | 处理 |
|-----------|-------------|------|
| `user` | `text` | 直接使用 content |
| `assistant` | `text` | 去除 `<think>` 块 |
| `tool` | `tool` | `tool_output: content` |

### extract_latest_user_text(messages)

从消息列表逆序查找，返回第一条 `role="user"` 的 content。

### prepare_recall_query(raw_query)

清洗后截断到 500 字符，优先保留完整单词。
