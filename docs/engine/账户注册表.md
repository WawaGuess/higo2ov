# 账户注册表

## 概述

`AccountRegistry` 管理 Higo 用户与 OpenViking account 的映射关系，支持懒创建和本地持久化。

---

## 数据结构

```python
class AccountEntry(TypedDict):
    account_id: str   # 与 higo_user_id 相同
    user_id: str      # OV account 下的默认用户
    api_key: str      # USER key
    created_at: str   # ISO8601
```

---

## 核心方法

### get_client(higo_user_id)

获取该 higo 用户对应的业务 Client（带缓存）：

```
get_client("higo_u001")
    ├──► 查缓存 → 命中直接返回
    ├──► 查 registry → 命中构建 Client
    └──► 懒创建 → _lazy_create()
```

### _lazy_create(higo_user_id)

带 `asyncio.Lock` 的并发安全创建：

1. 双重检查（获取锁后再次查 registry）
2. `account_id = higo_user_id`
3. 检查 account 是否存在（`GET /admin/accounts`）
4. 不存在则创建（`POST /admin/accounts`）
5. 注册用户（`POST /admin/accounts/{id}/users`）
6. 409 Conflict 时降级 regenerate key
7. 原子写入 `.account_registry.json`

---

## 持久化

### 写入

使用临时文件 + `os.replace` 实现原子写入：

```python
fd, tmp_path = tempfile.mkstemp(dir=dir_name, suffix=".tmp")
with os.fdopen(fd, "w", encoding="utf-8") as f:
    json.dump(self._registry, f, indent=2, ensure_ascii=False)
os.replace(tmp_path, self._registry_path)
```

### 读取

启动时从 `.account_registry.json` 加载，解析失败时返回空 dict。

---

## 并发安全

- `asyncio.Lock` 保护懒创建逻辑
- 锁内双重检查，避免重复创建
- 原子文件写入，避免数据损坏
