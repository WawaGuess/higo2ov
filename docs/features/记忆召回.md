# 记忆召回

## 概述

记忆召回在 transform 阶段基于当前用户输入搜索 OpenViking 中的相关记忆，经过后处理后注入到对话中。

---

## 搜索流程

### Query 准备

1. 从最后一条 `user` 消息提取文本：`extract_latest_user_text()`
2. 清洗：`prepare_recall_query()` 调用 `sanitize_user_text_for_capture()` 后截断到 500 字符

### 并行搜索

同时搜索 user scope 和 agent scope：

```python
tasks = [
    client.find(query, "viking://user/memories", limit=20, mode="auto"),
    client.find(query, "viking://agent/memories", limit=20, mode="auto"),
]
```

URI 通过 `_normalize_target_uri()` 规范化，考虑 `isolate_user_scope_by_agent` 和 `isolate_agent_scope_by_user` 配置。

---

## 后处理

### 1. 过滤 Directory Descriptions

排除 `.abstract.md` 和 `.overview.md` 文件：

```python
results = [r for r in results if not _is_directory_description(r)]
```

### 2. Query-Aware 排序

`_rank_for_injection()` 计算综合分数：

```
final_score = base_score
            + leaf_boost(0.12)       # level == 2
            + event_boost(0.1)       # wants_temporal and is event
            + preference_boost(0.08) # wants_preference and is preference
            + lexical_overlap(max0.2) # 查询词在 URI/abstract 中的匹配
```

Query profile 检测：
- `wants_preference`：prefer/like/喜欢/偏好 等
- `wants_temporal`：when/昨天/今天/上周 等

### 3. 去重

| 记忆类型 | 去重键 |
|---------|--------|
| events / cases | `uri` |
| 其他 | `abstract + category + normalized_text` |

### 4. 选择策略

```python
leaves = [item for item in deduped if _is_leaf_like_memory(item)]  # level == 2
if len(leaves) >= limit:
    return leaves[:limit]  # 只返回叶子

# 否则补充 non-leaf，按 score_threshold 过滤
picked = leaves + [non_leaf for non_leaf in deduped if score >= threshold][:remaining]
```

---

## 预算组装

`build_memory_lines_with_budget()`：
- 第一条记忆强制包含（有界溢出）
- 后续条目使用 `_count_tokens()`（tiktoken 优先）检查是否超预算
- 格式：`- [{category}] {content} ({score:.0%})`
