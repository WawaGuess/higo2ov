# 监控与统计

## 概述

监控模块提供两套能力：
1. **TurnCollector** — 每轮对话的 token 统计与数据聚合
2. **Monitor Dashboard** — Web UI + API 供运维查看

---

## TurnCollector

### 数据收集流程

**Transform 阶段 — 记录 Input Tokens**：

```python
TurnCollector.get_instance().start_turn(
    session_id=sid,
    round_id=request.round.roundId,
    seq=request.round.seq,
    messages=[m.model_dump() for m in new_messages],
    model_tokens=model_tokens,
    memory_text=memory_text,
    context_env_text=context_env_text,
)
```

**Result 阶段 — 记录 Output Tokens**：

```python
TurnCollector.get_instance().end_turn(
    round_id=round_id,
    sections=[s.model_dump() for s in request.message.sections],
    errors=[e.model_dump() for e in request.errors],
)
```

### 分块策略

`_chunk_input()` 将消息列表拆为 5 个类别：

| 类别 | 来源 | token 计算 |
|---|---|---|
| `system` | system 角色消息 | `_count_tokens(content) + 3` |
| `memory` | 注入的记忆文本 | `_count_tokens(content) + 3` |
| `context_env` | context environment 消息 | `_count_tokens(content) + 3` |
| `history` | 历史对话消息 | 每条 `+ 3` 后求和 |
| `user` | 当前用户输入 | `_count_tokens(content) + 3` |

`+3` 是消息格式标记（role label、分隔符）的粗略估算。

### Token 计数策略

优先使用 `tiktoken`（cl100k_base），失败时回退到字符估算（CJK ≈ 1 token/char，ASCII ≈ 0.25 token/char）。

### 数据模型

```python
@dataclass
class TurnRecord:
    turn_id: str
    session_id: str
    round_id: str
    seq: int
    created_at: float

    # Input
    system_prompt: str
    system_tokens: int
    user_input: str
    user_tokens: int
    history: List[dict]
    history_tokens: int
    memory_injected: str
    memory_tokens: int

    # Output
    assistant_output: str
    assistant_tokens: int
    reasoning: str
    tool_calls: List[dict]

    # Totals
    total_input_tokens: int
    total_output_tokens: int
    total_tokens: int

    chunks: List[dict]  # 供饼图展示
```

### 持久化

- 写入时机：`end_turn()` 完成后自动触发 `_persist_session()`
- 文件位置：`data/session_{session_id}.json`
- 加载时机：服务启动时 `_load_history()` 自动加载
- 内存限制：每 session 最多保留最近 50 轮 turn

## Monitor Dashboard

### 路由

| 路由 | 说明 |
|------|------|
| `GET /monitor` | Web UI 页面（static/index.html） |
| `GET /monitor/api/sessions` | 所有 session 列表 |
| `GET /monitor/api/sessions/{id}` | 单个 session 详情 |
| `GET /monitor/api/sessions/{id}/turns` | session 的所有 turns |
| `GET /monitor/api/turns/latest` | 最新 turn |

### Stats API

| 路由 | 说明 |
|------|------|
| `GET /api/stats` | 完整统计（含 session 明细） |
| `GET /api/stats/summary` | 轻量统计（仅聚合值） |

参数 `since`（Unix 时间戳）可按时间过滤。
