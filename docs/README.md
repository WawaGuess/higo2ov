## 代码与文档双向锚点规范

### 文档 → 代码

每篇文档末尾添加 `## 相关代码` 区块，用表格列出涉及的代码位置：

```markdown
## 相关代码

| 逻辑 | 文件 | 函数/类 |
|------|------|---------|
| 消息捕获 | `engine/openviking_engine.py` | `_capture_messages()` |
| 结果捕获 | `engine/openviking_engine.py` | `capture_round_result()` |
```

### 代码 → 文档

每个 Python 文件顶部添加注释，指向相关文档：

```python
# 相关文档:
#   - docs/features/消息捕获.md
#   - docs/decisions/002-会话历史补全.md
```

### 维护规则

- 代码文件重命名/函数改名 → 同步更新文档中的表格
- 文档目录结构调整 → 同步更新代码顶部注释
- 新增功能 → 必须同时建立双向锚点
